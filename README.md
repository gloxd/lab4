# Задание 1

### Текст задачи
Решить задачу на построение нового дерева по заданному (map). Дерево содержит строки. Заменить в каждой строке каждый символ на следующий по порядку.

### Алгоритм для задания 1
Шаг 1. Определение структуры дерева
Создается рекурсивный тип данных `BinaryTree`, который представляет собой либо пустое дерево `Empty`, либо узел `Node`, хранящий значение и два дочерних поддерева (левое и правое).

Шаг 2. Функция преобразования строки (shiftString)
Принимает на вход строку, раскладывает её в последовательность символов через `Seq.map` и сдвигает каждый символ по правилу: символ '9' переходит в '0', а 'я' переходит в 'а', остальные символы увеличивают свой код на 1. Затем символы собираются обратно в строку.

Шаг 3. Рекурсивный обход дерева (mapTree)
Использует сопоставление шаблонов (`match`). Для пустого дерева возвращает `Empty`, а для узла `Node` применяет функцию сдвига к текущему значению и рекурсивно вызывает себя для левого и правого поддеревьев, формируя новую структуру.

Шаг 4. Безопасный ввод данных (readInt)
Запрашивает у пользователя желаемое количество элементов дерева с клавиатуры. Использует `Int32.TryParse` для защиты от ввода некорректных символов или букв. При ошибке рекурсивно повторяет запрос.

Шаг 5. Поэлементная генерация в последовательность (inputRandomTree)
Создается список случайных элементов заданной длины. На каждой итерации цикла for генерируется строго один случайный символ, который сразу добавляется в результирующий список valuesList.

Шаг 6. Построение дерева по индексам (buildTreeFromList)
Полученная последовательность переводится в список. Функция строит бинарное сбалансированное дерево по принципу двоичной кучи, рассчитывая для каждого элемента с индексом `i` координаты левого потомка как `2 * i + 1`, а правого — как `2 * i + 2`.

Шаг 7. Вывод результатов
Программа выводит на экран сгенерированное случайное дерево в виде повернутой на 90 градусов структуры, применяет к нему функцию `mapTree` и выводит полученное преобразованное дерево.

# Задание 2

### Текст задачи
Решить задачу на получение заданного результата для указанного дерева (fold). Сформировать список из значений узлов с двумя листьями.

### Алгоритм для задания 2
Шаг 1. Сбор всех поддеревьев (getNodes)
Внутри функции `findNodesWithTwoLeaves` объявляется вспомогательная рекурсивная функция, которая обходит дерево и собирает плоский список из кортежей вида `(текущее_значение, левое_поддерево, правое_поддерево)` для каждого узла структуры.

Шаг 2. Фильтрация и свертка списка (List.fold)
Полученный плоский список узлов обрабатывается стандартной функцией свертки `List.fold`. Внутри аккумулятора для каждого узла проверяется шаблон его левого и правого поддеревьев.

Шаг 3. Проверка критерия "двух листьев"
С помощью сопоставления шаблонов (`match left, right`) отбираются только те узлы, у которых оба поддерева являются полноценными листьями (то есть структурами вида `Node(value, Empty, Empty)`). Если условие выполняется, значение текущего родительского узла добавляется в аккумулятор. В остальных случаях аккумулятор остается прежним.

Шаг 4. Ввод данных и построение второго дерева
Аналогично первому заданию.

Шаг 5. Поиск и вывод результата
К построенному дереву применяется функция свертки. Программа выводит на экран структуру сгенерированного дерева и печатает итоговый список значений тех узлов, у которых левый и правый дочерние элементы оказались листьями.
