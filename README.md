# Задание 1

### Текст задачи

Решить задачу на построение нового дерева по заданному (map)
Дерево содержит строки. Заменить в каждой строке каждый символ на
следующий по порядку.

### Алгоритм для задания 1
1. Для каждого числа в исходном списке:
   - Преобразовать число в строку
   - Разбить строку на отдельные символы-цифры
   - Преобразовать каждый символ в целое число
   - Найти максимальное значение среди полученных цифр
2. Собрать все максимумы в результирующий список
