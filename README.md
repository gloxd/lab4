# Задание 1

### Текст задачи

Решить задачу на построение нового дерева по заданному (map)
Дерево содержит строки. Заменить в каждой строке каждый символ на
следующий по порядку.

### Алгоритм для задания 1
Шаг 1. Определение структуры дерева

Создается дерево, которое может быть либо пустым, либо узлом, содержащим значение и два поддерева (левое и правое)

Шаг 2. Функция преобразования строки

Принимает на вход строку

Проходит по каждому символу строки

Для каждого символа проверяет:

Если символ '9' → заменяет на '0'

Если символ 'z' → заменяет на 'a'

Если символ 'Z' → заменяет на 'A'

Во всех остальных случаях заменяет на следующий символ (код символа + 1)

Собирает все преобразованные символы в новую строку

Шаг 3. Рекурсивный обход дерева (mapTree)

Если дерево пустое → возвращает пустое дерево

Если дерево содержит узел:

Применяет функцию преобразования к значению текущего узла

Рекурсивно вызывает себя для левого поддерева

Рекурсивно вызывает себя для правого поддерева

Создает новый узел с преобразованным значением и преобразованными поддеревьями

Шаг 4. Ввод данных

Запрашивает у пользователя строки для узлов через пробел

Разбивает введенную строку на отдельные элементы

Строит из полученных элементов бинарное дерево (обходом в ширину)

Пустые узлы обозначаются символом "_"

Шаг 5. Применение преобразования

Вызывает функцию mapTree с функцией преобразования строки

Получает новое дерево с измененными значениями

Шаг 6. Вывод результата

Выводит исходное дерево

Выводит преобразованное дерево

# Задание 2

### Текст задачи

Решить задачу на получение заданного результата для указанного дерева (fold)
Сформировать список из узлов с двумя листьями (узел является листом, если у
него нет ни левого, ни правого поддерева).

### Алгоритм для задания 1

Шаг 1. Определение понятия "лист"

Лист — это узел, у которого нет потомков (левое и правое поддеревья пустые)

В коде лист соответствует значению Empty

Шаг 2. Вспомогательная функция foldTree с информацией о листьях

Функция выполняет обход дерева и возвращает два значения:

Накопленный результат обхода

Флаг, является ли текущее поддерево листом

Работает рекурсивно:

Если поддерево пустое → возвращает (аккумулятор, true)

Если поддерево - узел:

Обрабатывает левое поддерево, получает результат и флаг "левый потомок - лист"

Обрабатывает правое поддерево, получает результат и флаг "правый потомок - лист"

Применяет функцию folder к текущему узлу

Возвращает (новый аккумулятор, false) так как текущий узел не лист

Шаг 3. Функция folder для отбора узлов

Принимает: значение узла, флаги левого и правого поддеревьев, текущий аккумулятор

Проверяет условие: являются ли оба поддерева листьями

Если условие выполняется → добавляет значение узла в начало аккумулятора

Если нет → возвращает аккумулятор без изменений

Шаг 4. Обход дерева

Запускает foldTree с начальным пустым списком []

Получает результат обхода и отбрасывает флаг (последний флаг всегда false)

Шаг 5. Ввод данных

Запрашивает у пользователя строки для узлов через пробел

Строит дерево аналогично первому заданию

Шаг 6. Поиск и вывод результата

Применяет алгоритм поиска к построенному дереву

Выводит список значений узлов, у которых оба потомка - листья

Если таких узлов нет, выводит соответствующее сообщение
