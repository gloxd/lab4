# Задание 1

### Текст задачи
Решить задачу на построение нового дерева по заданному (map). Дерево содержит строки. Заменить в каждой строке каждый символ на следующий по порядку.
Организовать поэлементный ввод количества элементов с последующим автоматическим заполнением бинарного дерева случайными строковыми значениями.

### Алгоритм для задания 1
Шаг 1. Определение структуры дерева
[cite_start]Создается рекурсивный тип данных `BinaryTree`, который представляет собой либо пустое дерево `Empty`, либо узел `Node`, хранящий значение и два дочерних поддерева (левое и правое)[cite: 19, 20].

Шаг 2. Функция преобразования строки (shiftString)
[cite_start]Принимает на вход строку, раскладывает её в последовательность символов через `Seq.map` и сдвигает каждый символ по правилу: символ '9' переходит в '0', 'z' переходит в 'a', 'Z' переходит в 'A', а остальные символы увеличивают свой код на 1[cite: 19]. [cite_start]Затем символы собираются обратно в строку[cite: 19].

Шаг 3. Рекурсивный обход дерева (mapTree)
Использует сопоставление шаблонов (`match`). [cite_start]Для пустого дерева возвращает `Empty` [cite: 21][cite_start], а для узла `Node` применяет функцию сдвига к текущему значению и рекурсивно вызывает себя для левого и правого поддеревьев, формируя новую структуру[cite: 22].

Шаг 4. Безопасный ввод данных (readInt)
[cite_start]Запрашивает у пользователя желаемое количество элементов дерева с клавиатуры[cite: 29]. [cite_start]Использует `Int32.TryParse` для защиты от ввода некорректных символов или букв[cite: 29]. [cite_start]При ошибке рекурсивно повторяет запрос[cite: 30, 31].

Шаг 5. Поэлементная генерация в последовательность (inputRandomTree)
[cite_start]На основе введенного числа создает ленивую последовательность (`seq`) элементов с помощью встроенного цикла `for`, внутри которого с помощью генератора случайных чисел `Random` создаются случайные буквенно-цифровые строки заданной длины[cite: 27, 28, 31, 32].

Шаг 6. Построение дерева по индексам (buildTreeFromList)
[cite_start]Полученная последовательность переводится в список[cite: 32]. [cite_start]Функция строит бинарное сбалансированное дерево по принципу двоичной кучи, рассчитывая для каждого элемента с индексом `i` координаты левого потомка как `2 * i + 1`, а правого — как `2 * i + 2`[cite: 26].

Шаг 7. Вывод результатов
[cite_start]Программа выводит на экран сгенерированное случайное дерево в виде повернутой на 90 градусов структуры [cite: 33, 34][cite_start], применяет к нему функцию `mapTree` [cite: 35] и выводит полученное преобразованное дерево.

# Задание 2

### Текст задачи
Решить задачу на получение заданного результата для указанного дерева (fold). Сформировать список из значений узлов с двумя листьями (узел является листом, если у него нет ни левого, ни правого поддерева).
Организовать ввод данных через поэлементную генерацию последовательности случайных узлов с помощью цикла `for`.

### Алгоритм для задания 2
Шаг 1. Сбор всех поддеревьев (getNodes)
[cite_start]Внутри функции `findNodesWithTwoLeaves` объявляется вспомогательная рекурсивная функция, которая обходит дерево и собирает плоский список из кортежей вида `(текущее_значение, левое_поддерево, правое_поддерево)` для каждого узла структуры[cite: 23, 24].

Шаг 2. Фильтрация и свертка списка (List.fold)
[cite_start]Полученный плоский список узлов обрабатывается стандартной функцией свертки `List.fold`[cite: 24]. [cite_start]Внутри аккумулятора для каждого узла проверяется шаблон его левого и правого поддеревьев[cite: 24].

Шаг 3. Проверка критерия "двух листьев"
[cite_start]С помощью сопоставления шаблонов (`match left, right`) отбираются только те узлы, у которых оба поддерева являются полноценными листьями (то есть структурами вида `Node(value, Empty, Empty)`)[cite: 24]. [cite_start]Если условие выполняется, значение текущего родительского узла добавляется в аккумулятор[cite: 24]. [cite_start]В остальных случаях аккумулятор остается прежним[cite: 25].

Шаг 4. Ввод данных и построение второго дерева
[cite_start]Аналогично первому заданию, программа запрашивает число элементов [cite: 29, 31][cite_start], запускает цикл `for` внутри блока `seq` для поэлементного создания новых случайных значений [cite: 31, 32][cite_start], переводит их в список [cite: 32] [cite_start]и строит новое бинарное дерево[cite: 32, 36].

Шаг 5. Поиск и вывод результата
[cite_start]К построенному дереву применяется функция свертки[cite: 36]. [cite_start]Программа выводит на экран структуру сгенерированного дерева и печатает итоговый список значений тех узлов, у которых левый и правый дочерние элементы оказались листьями[cite: 36].
